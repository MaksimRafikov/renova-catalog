# Каталог РеНова+

Каталог объектов (ремонт + дизайн «под ключ») для студии **РеНова+**, Уфа.  
Цель продукта: на встрече за ~30 секунд открыть «похожую квартиру» (ЖК / метраж), а не листать карусель Tilda.

## Статус репозитория

Каркас каталога поднят (static HTML/CSS/JS + Python как у **За Комфортом**).  
Стек утверждён: `docs/stack-choice.md`. Токены: `docs/design-tokens.md`.  
Референс UX (не клон визуала): **Ellis**.

## Источники правды

| Файл | Зачем |
| --- | --- |
| `CLIENT.md` | Досье клиента, контакты, хук письма, открытые вопросы |
| `STATUS.md` → `## Handoff` | Живое состояние сессии |
| `docs/stack-choice.md` | Решение по стеку |
| `docs/reference-zakomfortom.md` | Как устроен За Комфортом |
| `docs/reference-ellis.md` | Как устроен Ellis |
| `content/site.json` | Черновик контактов/бренда |
| `.ecc/session/atoms.md` | Короткие решения |

## Папки контента (как у За Комфортом)

```
inbox/           — сырые загрузки клиента (не в публичный деплой)
assets/          — продакшен-медиа по case-id
content/cases/   — JSON кейсов
content/site.json
docs/            — бриф, референсы, деплой
```

## Агент-протокол

Фазы и шаблоны: `NEW_CHAT_PLAYBOOK.md`.  
Короткий регламент наполнения: `WORKFLOW.md`.  
Не читать целиком референс-репозитории «на всякий случай» — только названные файлы.

## Не делать без явного запроса

- Копировать бренд/тексты/метрику За Комфортом или Ellis в прод РеНова+.
- Запускать полный `copy-assets` / тяжёлый медиа-batch без нужды.
- Force-push; публиковать `scripts/`, `content/`, `docs/` на Pages.
- Обещать клиенту сроки, пока нет полного комплекта материалов.
