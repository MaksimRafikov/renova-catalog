Лаконичный каталог для встреч — в духе РеНова+, не копия Ellis

Ниже — рабочие предложения по структуре и внешнему виду. Это не макет в Figma и не готовый сайт: схематичные экраны, чтобы быстро согласовать направление. Откройте файл в браузере и пролистайте сверху вниз.

Рекомендуемое направление

1. Общая идея

Каталог — инструмент встречи: за ~30 секунд найти похожую квартиру. Поэтому визуал спокойный, воздух, фото на первом плане. Бренд РеНова+ чувствуется через navy + один голубой акцент, логотип и чёткую типографику — без «пёстрых» плашек, градиентных кнопок и декоративных бейджей.

Берём от Ellis (смысл, не картинка)

  • Две ветки: Дизайн / Ремонт
  • Перекрёстные ссылки, если оба вида работ по одному объекту
  • Photo-first, мало текста на первом экране
  • Понятный путь назад и к контактам

Делаем иначе, чем Ellis / прошлые каталоги

  • Светлый mist-фон + navy, без «каменного» luxury-тёмного
  • Гротеск Manrope (ближе к Gotham бренда), без serif-заголовков Ellis
  • Другой верх кейса на десктопе (см. блок «Карточка»)
  • Фильтр ЖК + площадь остаётся pragmatic-инструментом встречи
Навигация

2. Шапка сайта — коротко и ясно

Слева логотип РеНова+. Справа только нужное: ветки каталога + действия. Без длинного меню «как на лендинге».

Схема шапки (десктоп)
Дизайн Ремонт Контакты Заявка Сайт РеНова+

На телефоне: логотип + «Заявка» всегда видны; остальное — в компактном меню или нижней панели действий.

Главная каталога

Не лендинг со статистикой. Один спокойный вход:

  • Крупно: РеНова+
  • Короткая фраза про подбор объекта
  • Две большие кнопки: Дизайн / Ремонт
  • Сразу ниже — сетка или переход в ветку

Что не кладём в первый экран

  • Цифры «N объектов / гарантия / пакеты»
  • Адрес офиса и юр. блок
  • Несколько конкурирующих заголовков
  • Карточки-украшения без клика
Фильтры + перекрёстные ссылки

3. Дизайн / Ремонт — и связь между ними

Верхний уровень — тип работ. Внутри ветки — привычные фильтры встречи: ЖК и площадь (комнатность/пакет — по желанию, вторично).

Дизайн Ремонт → внутри: ЖК Площадь
Объект в ЖК X → Кейс «Дизайн» ↔ Кейс «Ремонт»

Если сделали и дизайн, и ремонт

  • Два отдельных кейса (свой набор фото)
  • В каждом — блок «Смотрите также»: ссылка на пару
  • В сетке можно бейдж «есть и дизайн / и ремонт» — тонкий, не кричащий

Если только одно

  • Кейс живёт только в своей ветке
  • Перекрёстной ссылки нет — пустых кнопок не рисуем

Важно для данных: в таблице от Карины заранее пометить пары «дизайн ↔ ремонт» одним id-связки.

Нужен ваш выбор

4. Верх карточки кейса — три варианта вместо «растянутой обложки»

Сейчас у прошлых каталогов на десктопе обложка тянется во всю ширину — из‑за этого сайты разных студий визуально сливаются. Ниже три свежих композиции. Рекомендую вариант A.

ВАРИАНТ A · рекомендую

Сплит: фото слева · паспорт справа

Обложка не на всю ширину. Слева крупное фото (примерно 55–60%), справа белая «паспортная» колонка: ЖК, м², тип работ, короткая подпись, кнопка «Заявка» / перекрёстная ссылка.

Действия

5. Кнопки: контакты, заявка, основной сайт

Первичные

  • Заявка — форма (имя, телефон, ЖК/площадь по желанию). Это главный лид с каталога.
  • Позвонить / Позвонить менеджеру — tel: и WhatsApp рядом с формой (без имени в UI).
+

Вторичные

  • Контакты — отдельная короткая страница или якорь: телефон, адрес, мессенджеры.
  • Основной сайт — ссылка на remontvufe.ru (внешняя, без конкуренции с «Заявкой»).
Оставить заявку Позвонить Контакты Сайт РеНова+ ↗

Форму предлагаю простой модалкой или отдельной страницей «Заявка» — без длинного квиза. Поля: имя, телефон, комментарий («интересует похожий на …»). Куда уходит заявка — уточним (почта / мессенджер / CRM).

Сетка каталога

6. Как выглядят плитки в списке

Карточка в сетке

  • Фото 4:3 или 3:2
  • Подпись: ЖК · м²
  • Мелкая метка: Дизайн / Ремонт
  • Если есть пара — тонкая строка «есть и ремонт»

Внутри кейса ниже героя

  • Галерея фото
  • План / PDF — если есть
  • Видео — если есть
  • Перекрёстная ссылка + повтор CTA
